One Record button. That's the headline. 🔴

## ⏺️ One recording, two ways to look at it

Until now the Network view had its own Record button, so you could be capturing logs but not requests, or the other way round, and the button in the sidebar didn't always agree with the one in the toolbar. That's gone. Press Record (sidebar, toolbar, or ⌘R) and LogLens starts the log stream and the HTTP(S) proxy together. Stop stops both. 🛑

The Network view is gone too. 🗑️ Requests were already showing up in the list and in the timeline, so the third view was a second copy of the same data. What's left is List 📋 and Timeline 🎞️, and "Network" is a subsystem in the sidebar that you filter like anything else. 🌐

Select a request row in the list and the inspector shows the whole thing: headers, decoded body, cURL. 🕵️

## 🧭 Sidebar

- ✅ Click to select, click again to deselect. Selecting adds to whatever is already selected. No more ⌘-click, which I suspect nobody ever found. 😅 Right-click still has "Only This", plus a "Clear" for the whole section.
- 🔎 A search field above the lists. Type "braze" and only the matching apps, subsystems and categories stay.

## 🩹 Heal and the new Network menu

Heal now lives in a Network menu in the toolbar 🌐, next to the capture on/off switch, the decrypt policy, and the certificate actions (reinstall in simulators, trust on this Mac, forget pinned hosts, reveal in Finder). Turning "Capture HTTP(S) Requests" off stops the proxy and hides the requests it captured; turning it on starts the proxy right away. ⚡

## ⬆️ Check for updates

LogLens checks GitHub once a day for a newer release and shows a banner at the top of the window with Download and Release Notes buttons. 🎉 There's also LogLens ▸ Check for Updates… in the menu. Nothing installs itself; you download the dmg and drag it over the old one. 📦

## 🐛 Small stuff

- The "No events yet" hint still talked about ⌘-click. Fixed. ✏️
- The Capture menu has a "Capture HTTP(S) Requests" toggle and "Heal Network Connection" too, for keyboard people. ⌨️

## 📥 Install

Download the dmg, drag LogLens to Applications. Signed and notarized. ☑️ Needs macOS 15.
